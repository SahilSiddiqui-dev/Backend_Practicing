## HackerRank Gotchas to Watch

✅ Classes: forget to call `super()` in extended class constructor  
✅ Promises: forgetting to return in .then() breaks chain  
✅ async/await: not awaiting async functions causes race conditions  
✅ Short-circuit: || returns first truthy (not boolean!)  
✅ Modules: mixing default and named exports
