# LifeSync Wellness Tracker

A ReactJS application to track wellness activities and maintain streaks.

## Features
- Track wellness activities: Meditation, Exercise, Reading, Overslept, Skipped Routine
- Display activity streak (increases for positive, resets for negative)
- Show wellness tips randomly
- View latest 5 activities
- Reset tracker functionality

## Running the Project
```
npm install
npm run dev
```

## How It Works
**Positive Activities**: Meditation, Exercise, Reading - increases streak
**Negative Activities**: Overslept, Skipped Routine - resets streak to 0

## Technical Stack
- React 18
- Vite
- JavaScript (ES6+)
